🚀 Como este app chega na nuvem

API Flask com uma página web: usuários com entradas e saídas de dinheiro e controle de produtos em falta.

1

Código Python

Flask 3 + SQLAlchemy 2. O requirements.txt lista as dependências e o /health mostra se o banco responde.

Python 3.12Flask 3SQLAlchemy 2pyodbc
2

Azure CLI

Tudo é criado por linha de comando: az group create, az webapp up, az sql server create, az sql db create.

Resource GroupApp Service Plan F1Azure CLI
3

Azure App Service

O deploy envia o código, o Oryx roda o pip install no Azure e o app sobe com gunicorn app:app num container Linux.

Web App LinuxOryxgunicorn
4

Azure SQL Database

A conexão vem das App Settings (variáveis de ambiente). Nenhuma senha fica no código, e os dados sobrevivem a restarts e redeploys.
